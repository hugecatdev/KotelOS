# API, встраивание и настройки

## API

| шелл | python (`import kt`) | страница (`window.kt`) | что делает |
|---|---|---|---|
| `kt js <code> [arg...]`, `kt js -f файл [arg...]` | `kt.js(code, *args)` | - | выполнить JS на странице, вернуть значение; если код - функция, аргументы уходят в неё строками |
| - | - | `kt.gesture(текст, кнопка, fn)` | `fn` там, где браузер требует жест пользователя (выбор файлов, разрешения), результат - из `await`. Если команду только что набрали, Enter и есть жест (браузер считает его ~5 с), `fn` вызывается сразу; иначе страница показывает кнопку |
| - | `kt.events()`, `kt.wait(name)`, `@kt.on(name)` + `kt.run()` | `kt.emit(name, data)` | события со страницы в гостя |
| `kt dl <file>` | `kt.dl(path)`, `kt.dl(data, name)` | - | файл из гостя в браузер (папка -> .tar.gz) |
| `kt up [dir]` | `kt.up(dir)` | `kt.write(path, data)` | файлы из браузера в гостя |
| `kt sync [dir]`, `-l`, `-u dir` (пакет `sync`) | - | - | копия папки с диска, правки из машины пишутся обратно (Chrome, Edge) |
| `kt copy`, `kt paste` | `kt.copy(s)`, `kt.paste()` | - | буфер обмена |
| `kt cfg [key [value]]` | `kt.cfg[key]`, `kt.cfg[key] = v` | `kt.cfg[key]`, `kt.cfg[key] = v` | реестр настроек |
| `kt save [имя]`, `kt load [имя]`, `kt snap`, `kt reset [-b]` | `kt.save(name="")` | `kt.save()` | сохранение машины и снимки в IndexedDB |
| `kt pack имя путь...`, `kt unpack имя [куда]` (пакет `pack`) | - | - | файлы в браузер и обратно, в любую машину |
| `kt info` | `kt.info()` | - | что знает страница: браузер, экран, пояс, бандл, образ, память, сохранение |
| `kt tty`, `kt tty new [команда]`, `kt tty N`, `kt tty kill N` (пакет `kt-ttyd`) | - | `kt.tty.list()`, `open(cmd, host, keys)`, `go(id)`, `kill(id)`, `input(id, s)`, `font(id, d)`, `attach(id, host, keys)` | виртуальные консоли: список, новая, перейти, закрыть; на клавиатуре Alt+1..9 |
| `kt screen [on\|off]` | - | `kt.screen(on)` | экран поверх терминала: клавиатура и мышь - в машину (нужен `boot.vga on`, см. [screen.md](screen.md)) |
| `kt export [имя]`, `kt import` | - | - | сохранение в файл / из файла |
| `kt font [имя] [размер]`, `kt theme [имя]` | - | - | шрифт и тема |
| `kt notify [text]` (пакет `notify`, код - `/usr/lib/kt-notify.js`) | `kt.notify(s)` | - | системное уведомление (первый раз спросит разрешение; нужен https или localhost, через file:// браузер их не даёт - только мигает заголовок вкладки) |
| `kt alert [text]`, `kt confirm text`, `kt prompt text [default]` (пакет `notify`) | - | - | родные окна браузера: alert, да/нет кодом выхода, строка на stdout. Пока окно открыто, страница и машина стоят |
| `kt pkg [add\|rm <name>]` | - | - | пакеты |
| - | - | `kt.exec(cmd)`, `kt.read(path)` | выполнить команду / прочитать файл в госте |
| - | - | `kt.type(text)`, `kt.fit()` | ввод в терминал, подогнать размер |

`kt` без аргументов - "kontrol utility" с версией и список модулей,
`kt help <модуль>` - подробно, `kt -v` - версия. Версия - хеш образа, тот же,
что `image:` в `kt info` и в `images/build.json`; лежит в
`/etc/os-release` (`VERSION_ID`), который `build.sh` дописывает отдельным
маленьким cpio после хеширования base + overlay.
HTTP - пакетами `curl`, `wget`, `python-requests` (см. [packages.md](packages.md)); у самого `kt`
скачивания нет, внутри это функция `kt_get` из `/usr/lib/kt.sh`, ей пользуется
`kt pkg`.
Модуль - исполняемый файл `/usr/lib/kt/<имя>` со строкой
`kt_meta "<аргументы>" "описание" "$@"`, из неё строится список в `kt`.
Расшифровка аргументов для `kt help <модуль>` - в переменной `KT_HELP` перед
этой строкой, по строке на флаг.

Примеры - `kt pkg add examples` (все) или по отдельности: `examples-python`,
`examples-c` (Мандельброт через tcc, картинку показывает `show.py`),
`examples-lua` (жизнь).
Питоновские написаны под MicroPython (`py`), работают и в CPython: `examples-python`
тянет `python-mpy|minipython`, `examples-c` - `micropython|minipython`. У micropython куча 1 МБ, для больших данных -
`micropython -X heapsize=16M` (так делает `run.sh` в C-примере, без micropython он зовёт `python3`):

| файл | что показывает |
|---|---|
| `cam.py [ширина]` | веб-камера в цвете в терминале: полублоки и 256 цветов, кадр берёт `kt.js`; во весь экран, после выхода экран прежний |
| `timer.py [25m\|90s\|5:00] [текст]` | большие цифры и полоса под командой, время в заголовке вкладки, в конце звонок; по умолчанию минута |
| `speak.py текст` | синтез речи браузера, голос под язык текста |
| `qr.py текст` | QR-код в терминале: страница грузит npm-пакет `qrcode` с esm.sh, питон рисует полублоками |
| `weather.py [город]` | погода на неделю с open-meteo: шкала температур, осадки; без города - по геолокации браузера |
| `monitor.py` | окно на странице: процессор с графиком за минуту, память, процессы |
| `paint.py` | рисовалка на странице: цвета, толщина, PNG пишется в `~/drawing.png` |
| `snake.py` | змейка во весь экран, после выхода экран прежний |
| `tkdemo.py` | обычный tkinter: вкладки, форма, рисование на Canvas, список, меню, диалоги; лежит в пакете `python-tkinter` и ставится вместе с ним, а не с `examples-python` |
`import kt` работает и в MicroPython (`py`), и в CPython (`python`): `kt.py` лежит в базовом образе.

```python
import kt
kt.cfg["term.font"] = 16          # числа - числами, on/off - True/False
kt.js("(a, b) => a + b", 2, 40)   # аргументы уходят в JS как JSON
kt.js("kt.cfg()")                 # все настройки dict'ом
kt.js("() => kt.term.cols")       # функция без аргументов тоже вызывается

@kt.on("click")
def click(data):
    print(data)

kt.run()                          # kt.stop() из обработчика - выйти
```

После восстановления сохранения или снимка из бандла страница шлёт событие
`restore` - по нему можно заново нарисовать свой DOM.

События копятся в `/run/kt/events`, только пока их кто-то слушает: первый
`kt.poll()` (он же внутри `events`, `wait` и `run`) ставит отметку
`/run/kt/ev.<pid>`, и без живых отметок агент событие не пишет, а журнал
удаляет. При выходе слушатель снимает отметку, последний забирает и журнал;
отметку убитого слушателя агент снимет на следующем событии.

## Встраивание

Сайт встраивает kotelos в iframe и зовёт API через `postMessage`:

```js
vm.contentWindow.postMessage({ kt: 1, method: "exec", args: ["uname -a"] }, "*");
// ответ: { kt: 1, result: { code, out, err } }   готовность: { kt: "ready" }
```

Методы: `exec`, `read`, `write`, `type`, `emit`, `save`, `cfg`.
Для встраивания удобен маленький бандл, например `python3 bundle.py -o embed.html -n embed --snap`.

## Настройки (`kt cfg`)

| ключ | по умолчанию | |
|---|---|---|
| `save.auto` | on | сохранять машину при сворачивании вкладки |
| `save.timer` | 0 | сохранять каждые N минут (0 - нет) |
| `term.font` | 13 (12 на телефоне) | размер шрифта |
| `term.family` | system | шрифт: system или любой с Google Fonts по имени (`kt font Space Mono`); jetbrains, fira, ibm, ubuntu, source, vt323 - короткие имена. Грузятся только при выборе |
| `term.theme` | dark | цвета: dark, light, amber, green, gray (три последних - монохромные, как старые мониторы) |
| `term.render` | dom | чем рисовать терминал: dom (встроенный в xterm, меньше памяти на экранах с высокой плотностью) или canvas (рамки и блоки точно по клеткам) |
| `term.cursor` | block | block, bar, underline |
| `term.blink` | off | мигание курсора; выключено, потому что в фокусе оно всё время занимает процессор (4.5% ядра на DOM-рендере, 1.5% на canvas) |
| `term.scroll` | 5000 | строк в прокрутке |
| `term.mobile` | on на телефоне | интерфейс телефона (на ПК - потестить) |
| `keys.main` | см. ниже | кнопки под терминалом |
| `keys.more` | см. ниже | кнопки под ⋯ |
| `keys.screen` | см. [screen.md](screen.md) | кнопки под экраном (`kt screen on`) |
| `keys.open` | off | показать кнопки под ⋯ |
| `keys.size` | 16 | размер подписей кнопок |
| `boot.mem` | 128 | память при загрузке с ядра, МБ |
| `boot.vga` | off (`--vga` бандла - on) | экран: видеопамять 4 МБ и `/dev/fb0` при загрузке с ядра |
| `boot.cmd` | | команда в новой машине (после загрузки с ядра или со встроенного снимка) |
| `boot.log` | off | лог загрузки ядра и init-скриптов |
| `pkg.repo` | `--repo` бандла (`/repo`) | откуда `kt pkg` берёт пакеты |

`kt font` - список шрифтов, `kt font jetbrains 15` - шрифт и размер сразу,
`kt theme` - темы с образцом, `kt theme amber` - выбрать.

Кнопки задаются как `extra-keys` в Termux, рядами:
`kt cfg keys.main "[['ESC','^C','|','UP','MORE'],['TAB','CTRL','ALT','LEFT','DOWN','RIGHT','KBD']]"`.
Имена: ESC TAB ENTER BKSP SPACE CTRL ALT UP DOWN LEFT RIGHT HOME END PGUP PGDN
DEL INS F1..F12, `^X` - Ctrl+X, MORE - показать `keys.more`, KBD - клавиатура
телефона; всё остальное печатается как есть (можно целую команду).
По умолчанию в первом ряду ESC / - | ~ HOME ↑ END ⋯, во втором TAB CTRL ALT > $
← ↓ → ⌨, под ⋯ - F1..F6 PGUP { } и F7..F12 PGDN [ ], по 9 в ряд, как основные
(Ctrl+буква - через CTRL в основном ряду).
В рядах длиннее 9 кнопок подписи мельче, чтобы не слипались на узком экране.

`kt cfg -r ключ` - вернуть ключ по умолчанию, `kt cfg -r` - все сразу.
`kt cfg ключ значение` печатает только новое значение.

Кроме встроенных `kt cfg` хранит свои ключи вида `имя.ключ` (например `ai.key`):
строки до 64 КБ, пустое значение удаляет ключ, `kt cfg имя.ключ` без значения у
незаданного ключа - пустой вывод и код 1. Неизвестный ключ в пространстве
встроенных (`term.fnt`) - ошибка, чтобы опечатки не терялись. Страница только
хранит пары ключ-значение и проверяет свои ключи, которые применяет сама;
описания для списка лежат в образе, в `/usr/share/kt/cfg/` строками
`ключ описание`: `kt` - встроенные, пакеты кладут свой файл (`ai`). Ключи из
описаний без значения в списке показываются как `""`.

Хранятся в localStorage (`kt.cfg`), только изменённые ключи. `boot.mem`,
`boot.vga` и `boot.log` действуют при загрузке с ядра: сохранённая машина и встроенный снимок
восстанавливаются как были (`kt reset` или `kt reset -b`).
В адресе: `?fresh` - не брать сохранение, `?boot` - загрузиться с ядра (если оно
есть в файле), `?cmd=...` - выполнить команду,
`?log` - показать лог загрузки один раз, `?reset` - сбросить все настройки
(например, если `boot.mem` выставлен слишком большим; машину не трогает,
вместе с `&fresh` - ещё и загрузиться начисто).

Ctrl+Alt+End два раза за 3 секунды (на телефоне CTRL ALT END кнопками, тоже
дважды) - сбросить все настройки и удалить сохранение этого бандла, страница
перезагрузится. Это делает сама страница, без гостя: выручает, когда машина не
отвечает и `kt reset` не работает (например, восстановилось сохранение старой
сборки с агентом на TTY). Снимки не трогает. Одно нажатие ничего не делает и в
машину не уходит.
