# «Отечественная ОС»: рабочий стол в духе KDE на JWM, тема «Трава» (белая панель, зелёные заголовки и
# выделение, плоско, без скруглений), обои - кубик. Программы оконные и лёгкие, под своими именами:
# xterm, xclock, xeyes, feh, xkill, micropython, lbreakout2, своё окно «О системе» (greenos-about);
# FOX (Xfe, xfa, xfi, Adie, Calculator, ShutterBug, ControlPanel - build-fox.sh), значки на рабочем столе
# (idesk - build-idesk.sh); с GitHub - xroach и oneko (build-extras.sh), системный монитор xosview
# (build-xosview.sh); рисовалка
# AzPainter (официальный GitLab автора - build-azpainter.sh):
# меню берёт то, что установлено. KotelOS не видно: --title (вкладка, строка загрузки), имя машины,
# подсказки kt при входе (--prep rm: файла подсказок в машине нет), вместо startx - greenos-start с заставкой и
# os-release (VERSION_ID - прежний, его показывает kt); kt-xclipd (общий с браузером буфер) остаётся.
# Не пакеты: JWM и greenos-about (bundles/greenos/root - собирает build.sh, в git не идёт), тема,
# значки, обои (fs), скрипты (bin) - данные этого бандла. X не в снимке (--cmd startx): обои и панель -
# под настоящий экран; --prep fc-cache - кэш fontconfig (триггер перепакованного fontconfig не срабатывает).
# «Сохранить сеанс» в меню - kt save; в Xfe правая кнопка - «Сценарии» - «Скачать» - kt dl
# (fs/root/.config/xfe/scripts); ответ обоих - уведомлением herbe. --no-3d: программ OpenGL здесь нет.
# Громкость - значок на панели (greenos-volume, amixer; полоска - xob). Громкость SB16 после сброса -
# по -14 дБ на мастере и ЦАП, звук игр почти не слышен: --prep ставит мастер 0 дБ и PCM -10 дБ (страница
# добавляет к ЦАП ещё x3, итог ~1); из alsa-utils нужен только amixer, остальное - в --drop.
# --drop - чего из пакетов в образе нет: библиотеки, которые не грузит ни одна программа
# (scripts/deadlibs.py bundles/greenos/greenos.txt), демо imlib2 (rgb.txt нужен загрузчику XPM).
