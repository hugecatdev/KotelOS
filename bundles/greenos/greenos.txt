# GreenOS - своя сборка, не для сайта (scripts/pages.sh берёт только bundles/*.txt):
#   bundles/greenos/build.sh && bundles/greenos/build-fox.sh && bundles/greenos/build-idesk.sh &&
#   ./release.py bundles/greenos/greenos.txt   -> site/greenos/index.html (~24 МБ)
# «Отечественная ОС»: рабочий стол в духе KDE на JWM, тема «Трава» (белая панель, зелёные заголовки и
# выделение, плоско, без скруглений), обои - кубик. Программы оконные и лёгкие, под своими именами:
# xterm, xcalc, xclock, xeyes, feh, xkill, micropython, lbreakout2, своё окно «О системе» (greenos-about);
# FOX (Xfe, xfa, xfi, Adie, Calculator, ShutterBug, ControlPanel - build-fox.sh), значки на рабочем столе
# (idesk - build-idesk.sh):
# меню берёт то, что установлено. KotelOS не видно: --title (вкладка, строка загрузки), имя машины,
# подсказки kt при входе (пустой hints.sh), вместо startx - greenos-start с заставкой и
# os-release (VERSION_ID - прежний, его показывает kt); kt-xclipd (общий с браузером буфер) остаётся.
# Не пакеты: JWM и greenos-about (bundles/greenos/root - собирает build.sh, в git не идёт), тема,
# значки, обои (fs), скрипты (bin) - данные этого бандла. X не в снимке (--cmd startx): обои и панель -
# под настоящий экран; --prep fc-cache - кэш fontconfig (триггер перепакованного fontconfig не срабатывает)
--snap --vga 8 --mem 256 --worker --title GreenOS
--prep fc-cache
--prep "sed -i 's/^NAME=.*/NAME=GreenOS/;s/^ID=.*/ID=greenos/;s/^PRETTY_NAME=.*/PRETTY_NAME=\"GreenOS 1.0\"/' /usr/lib/os-release"
--cmd greenos-start
--file bundles/greenos/xinitrc:/root/.xinitrc
--file bundles/greenos/fs:/
--file bundles/greenos/root:/
--file bundles/greenos/bin/greenos-run:/usr/bin/greenos-run
--file bundles/greenos/bin/greenos-menu:/usr/bin/greenos-menu
--file bundles/greenos/bin/greenos-wallpaper:/usr/bin/greenos-wallpaper
--file bundles/greenos/bin/greenos-start:/usr/bin/greenos-start
