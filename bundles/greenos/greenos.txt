# GreenOS - своя сборка, не для сайта (scripts/pages.sh берёт только bundles/*.txt):
#   bundles/greenos/build.sh && bundles/greenos/build-fox.sh && bundles/greenos/build-idesk.sh &&
#   bundles/greenos/build-extras.sh && bundles/greenos/build-azpainter.sh && bundles/greenos/build-xosview.sh &&
#   bundles/greenos/build-ted.sh && ./release.py bundles/greenos/greenos.txt   -> site/greenos/index.html (~32 МБ)
# «Отечественная ОС»: рабочий стол в духе KDE на JWM, тема «Трава» (белая панель, зелёные заголовки и
# выделение, плоско, без скруглений), обои - кубик. Программы оконные и лёгкие, под своими именами:
# xterm, xclock, xeyes, feh, xkill, micropython, lbreakout2, своё окно «О системе» (greenos-about);
# FOX (Xfe, xfa, xfi, Adie, Calculator, ShutterBug, ControlPanel - build-fox.sh), значки на рабочем столе
# (idesk - build-idesk.sh); с GitHub - herbe (уведомления), xroach и oneko (build-extras.sh), системный
# монитор xosview (build-xosview.sh); рисовалка AzPainter (официальный GitLab автора - build-azpainter.sh);
# текстовый процессор Ted на Motif (официальное зеркало автора - build-ted.sh; .rtf из Xfe - в нём):
# меню - эти программы, без проверок «а вдруг нет». KotelOS не видно: --title (вкладка, строка загрузки), имя машины,
# подсказки kt при входе (fs/etc/profile.d/hints.sh пустой - их нет и на экране снимка, --prep rm - и файла нет) и
# os-release (VERSION_ID - прежний, его показывает kt); kt-xclipd (общий с браузером буфер) остаётся.
# Не пакеты: JWM и greenos-about (bundles/greenos/root - собирает build.sh, в git не идёт), тема,
# значки, обои (fs), служебные скрипты (lib -> /usr/lib/greenos: меню, обои, громкость; в PATH только
# greenos-about) - данные этого бандла. X не в снимке (boot.cmd=startx): обои и панель -
# под настоящий экран; --prep fc-cache - кэш fontconfig (триггер перепакованного fontconfig не срабатывает).
# «Сохранить сеанс» в меню - kt save; в Xfe правая кнопка - «Сценарии» - «Скачать» - kt dl
# (fs/root/.config/xfe/scripts); ответ обоих - уведомлением herbe. --no-3d: программ OpenGL здесь нет.
# Громкость - значок на панели: щелчок - ползунок mixer (как в MATE), колесо - volume
# (amixer; полоска - xob). Громкость SB16 после сброса -
# по -14 дБ на мастере и ЦАП, звук игр почти не слышен: --prep ставит мастер 0 дБ и PCM -10 дБ (страница
# добавляет к ЦАП ещё x3, итог ~1); из alsa-utils нужен только amixer, остальное - в --drop.
# --drop - чего из пакетов в образе нет: библиотеки, которые не грузит ни одна программа
# (scripts/deadlibs.py bundles/greenos/greenos.txt), демо imlib2 (rgb.txt нужен загрузчику XPM).
# Звук: SB16 машины, alsa-lib - её SDL берёт сам (сервер не нужен), страница играет после первого касания.
# fs/etc/asound.conf - карта только на 22050 Гц: sdl12-compat открывает её не ниже 44100 и пересчитывает
# звук игры 22050 -> 44100 плавающей точкой - в v86 это 44% процессора на LBreakout2 вместо 21%;
# fs/root/.lgames/lbreakout2.conf - буфер звука игры 1024 вместо 512 (реже просыпается, 17%; без звука 5%)
# pkg.repo - пакеты kt pkg add с сайта KotelOS на GitHub Pages (там CORS открыт): GreenOS - отдельный файл,
# своего /repo рядом нет. Приглашение шелла - как в Ubuntu (fs/etc/profile.d/prompt.sh, после
# /etc/profile KotelOS); в xterm шелл входной (loginShell в Xdefaults) - читает его же.
# --cfg screen.cursor=off - над экраном только курсор X, без второго курсора браузера поверх.
# Браузер - Dillo (Alpine, FLTK, без JavaScript; с ним GNU wget и сертификаты), шрифты - fs/root/.dillo.
# В интернет он ходит только с релеем: меню «Система» - «Сеть» (/usr/lib/greenos/net -> kt net), по
# умолчанию сеть - fetch (только HTTP через страницу).
